# Hướng dẫn nút bấm Fujifilm X-T10

Trang hướng dẫn tương tác giúp người mới làm quen với các nút bấm và bánh xoay trên máy ảnh Fujifilm X-T10.

**Xem trang:** https://kayz-ng.github.io/hdsd-fuji-xt10/

## Trang có gì

- **Sơ đồ ba mặt máy:** mặt trên, mặt sau và mặt trước. Chạm vào vòng tròn vàng trên sơ đồ, hoặc chọn tên nút ngay dưới hình, để xem nút đó dùng làm gì.
- **Từng lựa chọn của mỗi nút:** với bánh tốc độ, bánh bù sáng, khẩu độ, nút lấy nét, bánh DRIVE và menu nhanh Q, chọn từng lựa chọn để xem giải thích và ảnh minh họa thay đổi ra sao.
- **Menu nhanh Q:** ISO, cân bằng trắng, giả lập màu (Provia, Velvia, Astia, Classic Chrome, Pro Neg, đen trắng, Sepia), dải tương phản động (DR) và bộ cài đặt C1–C7.
- **Thiết lập chế độ A cho người mới:** bật công tắc ở góc trên để xem lần lượt các bước đặt máy ở chế độ ưu tiên khẩu độ.

## Cập nhật trang

Toàn bộ trang nằm trong một file `index.html`, không cần cài đặt hay build gì.

1. Thay file `index.html` bằng bản mới.
2. Đẩy lên GitHub:

   ```bash
   git add index.html
   git commit -m "Cập nhật trang hướng dẫn"
   git push
   ```

3. Đợi khoảng một phút để GitHub Pages cập nhật.

## Lưu ý

- Sơ đồ máy là hình vẽ đơn giản để chỉ vị trí tương đối, không đúng tỷ lệ.
- Ảnh minh họa chỉ thể hiện xu hướng thay đổi, không phải ảnh chụp thật. Màu của các giả lập phim chỉ gần đúng, nên chụp thử trên máy để thấy màu thật.
- Tên nút và vị trí theo sách hướng dẫn chính hãng của Fujifilm X-T10. Tên mục menu có thể hơi khác tùy phiên bản firmware.
